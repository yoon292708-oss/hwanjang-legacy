# ⚔️ 환장 래거시 (Hwanjang Legacy)

사계절 오픈월드(마을·봄·대초원·여름·바다·사막·가을·고대 유적지·겨울·결투장) + 11종 직업 전직 + 던전 + 실시간 멀티플레이 3D 웹 MMORPG입니다.

## 로컬 실행
```bash
node server.js
```
실행 후 `http://localhost:3005/` 접속 (또는 Windows에서 `환장래거시_실행.bat` 실행).

## 무료 24시간 클라우드 배포 (Render.com)
1. 이 저장소를 GitHub에 푸시합니다.
2. [Render.com](https://render.com)에서 **New + → Blueprint** (또는 **Web Service**) 선택 후 이 GitHub 저장소를 연결합니다.
3. `render.yaml` 설정대로 자동 배포되며, 발급된 `https://xxxx.onrender.com` 고정 주소로 PC를 꺼도 24시간 친구와 함께 접속할 수 있습니다.
   *(무료 플랜에서 서버가 재시작되어도 브라우저에 자동 백업된 캐릭터 데이터가 로그인 시 서버로 자동 복구됩니다.)*
